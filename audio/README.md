# Drum samples

The local MP3 files are previews from soneproject's `acoustic-drumkit-1` pack on Freesound. The recordings are acoustic drums captured with a Zoom H1 in a jazz bar, and each source is marked Creative Commons 0 (CC0).

Source pack: https://freesound.org/people/soneproject/packs/25895/

Source sounds:

- `kick.mp3`: sound 459287, `kick4B.flac`
- `snare.mp3`: sound 459315, `snare14G5.flac`
- `tom-low.mp3`: sound 459267, `tom7D.flac`
- `tom-mid.mp3`: sound 459266, `tom7C.flac`
- `tom-high.mp3`: sound 459255, `tom7B.flac`
- `hi-hat.mp3`: sound 459327, `hat50.flac`
- `crash-left.mp3`: sound 459214, `ride4.flac`
- `crash-right.mp3`: sound 459213, `ride3.flac`
- `ride.mp3`: sound 459219, `ride1.flac`

The files are hosted locally so the interactive test does not depend on a third-party request at playback time. The source page states that CC0 sounds can be copied, modified, distributed and used commercially without requesting permission.
